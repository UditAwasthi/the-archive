# Philosophy

## Core Principles

1. **Ship early, iterate often.** Perfection is the enemy of progress.
2. **Write code for humans first, machines second.**
3. **Every complex system that works evolved from a simple system that worked.**
4. **Learn by building.** Theory without practice is incomplete.
5. **Open source is a superpower.** Give back more than you take.
6. **Stay curious.** The best engineers are perpetual students.

---

These principles are not fixed. They evolve with experience.
